# 槐芽网络训练营 🌱

面向小学生的电子产品与网络文化安全教育闯关网页游戏。浏览器直接打开即玩，免注册、无下载，以趣味闯关、图文答题的形式帮助小学生学会择优用网、理性用机、主动避害。

> 核心宗旨：不禁止用网、不抵制电子产品，**学会择优使用、理性把控、主动避害**。

## 玩法

- **4 大主题关 + 1 个终极试炼关**，顺序解锁：
  1. 🗺️ 网络宝藏甄别师 -- 认识优质网络内容
  2. 🧹 网络垃圾清除官 -- 远离低质有害内容
  3. ⏰ 合理用机小达人 -- 规范使用习惯
  4. 🛡️ 网络安全小卫士 -- 基础网络防护
  5. 🏆 全网素养大试炼 -- 16 题池随机抽 10 题综合考核
- 全程仅点击操作（判断 / 单选 / 多选），100% 图文结合出题
- 答错不批评、不卡关：温和提示 + 通俗知识点讲解
- 答对攒积分、通关收勋章，全通关后可下载「青少年健康上网小能手」电子证书（可写上自己的名字）
- 进度自动保存在本地浏览器，下次打开继续玩


## 技术栈

Vite + TypeScript + 原生 DOM，无框架、无后端；题库 JSON 数据驱动；音效 WebAudio 代码合成；证书 Canvas 绘制。
