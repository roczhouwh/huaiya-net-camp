# 槐芽网络训练营 · 开发方案

> 需求来源：[小学生电子产品与网络文化安全教育闯关小游戏（网页版）完整需求方案](./小学生电子产品与网络文化安全教育闯关小游戏（网页版）完整需求方案.md)
> 本文档记录 2026-08 需求评审（grilling）后确定的全部技术决策与实施计划。

## 一、项目定位

面向小学生的轻量益智闯关网页游戏，浏览器直接打开即玩，免注册。以趣味闯关、图文答题为核心形式，帮助小学生建立正确的电子产品与网络使用认知。核心宗旨：**不禁止用网、不抵制电子产品，学会择优使用、理性把控、主动避害**。

## 二、已确定的核心决策

| 维度 | 决策 |
|---|---|
| 技术栈 | Vite + TypeScript + 原生 DOM（无框架），题库 JSON 数据驱动，产物纯静态 |
| 页面流程 | 首页 → 闯关大厅（顺序解锁）→ 答题 → 单关结算+知识小结 → 勋章中心 → 通关证书 |
| 关卡结构 | 4 主题关（各 4 题）顺序解锁 → 终极关（16 题池随机抽 10 题） |
| 题型 | 判断 / 单选 / 多选，全部点击操作；多选题带「确认」按钮 |
| 判定规则 | 答错即讲当题放行、零失败感；积分 = 答对题数；通关即得勋章 |
| 配图 | 开发期统一 SVG 占位；16 张题目主图由 AI 按需求文档关键词生成后放入 `assets/images/`；反馈环节不单独配图，用 CSS 动画 + 表情图标 + 题目原图复用 |
| 语音朗读 | **砍掉**（需求文档中该功能取消），界面不保留语音开关 |
| 音频 | BGM / 答题音效全部 WebAudio 代码合成，无音频资源文件；界面保留一个音效总开关 |
| 证书 | Canvas 绘制「青少年健康上网小能手」电子证书，输入昵称（默认 **小槐芽**，可跳过），一键下载 PNG |
| 进度保存 | localStorage：通关进度、勋章、积分、设置项，下次打开可继续 |
| 部署 | GitHub（public）+ Vercel，域名 `huaiya.535334587.xyz`（Cloudflare 子域） |
| 离线能力 | Vite 构建使用相对路径 `base: './'`，产物 zip 解压后双击 `index.html` 即可玩（学校无外网场景） |
| 多端适配 | 响应式，移动优先布局，适配电脑 / 平板 / 手机浏览器 |

## 三、页面与路由

单页应用，hash 路由（纯静态托管友好，无需服务端重写配置）：

| 路由 | 页面 | 说明 |
|---|---|---|
| `#/` | 首页 | 游戏标题、卡通主视觉、「开始闯关」按钮、音效开关入口 |
| `#/hall` | 闯关大厅 | 4 主题关 + 终极关入口卡片，未解锁置灰，显示各关进度/勋章 |
| `#/level/:id` | 答题页 | 统一版式：顶部关卡标题+趣味小标题 / 中间场景配图 / 题目文字 / 底部选项按钮 |
| `#/result/:id` | 单关结算 | 积分、答对题数、专属勋章获得动画、本关知识小结 |
| `#/medals` | 勋章中心 | 5 枚勋章收集状态、总积分展示 |
| `#/cert` | 通关证书 | 四关+终极关全通后解锁；昵称输入（默认小槐芽）、Canvas 证书预览、下载 PNG |

## 四、数据模型

### 4.1 题库 `src/data/questions.ts`

```ts
type QuestionType = 'judge' | 'single' | 'multi'

interface Question {
  id: string                 // 如 'q1-1'（关卡1第1题）
  levelId: 1 | 2 | 3 | 4     // 所属主题关
  type: QuestionType
  image: string              // 配图路径 assets/images/q1-1.png
  text: string               // 题目原文
  options: string[]          // 选项（判断题为 ['正确','错误']）
  answer: number[]           // 正确答案索引数组（多选多个）
  explain: string            // 答错时的通俗解析话术
}
```

- 题目内容 100% 来自需求文档第十一章，共 16 题（每关 4 题）。
- 终极关从 16 题池 `shuffle()` 随机抽 10 题，沿用原题与配图。

### 4.2 关卡 `src/data/levels.ts`

```ts
interface Level {
  id: number                 // 1-4 为主题关，5 为终极关
  name: string               // 如「网络宝藏甄别师」
  subtitle: string           // 趣味小标题
  emoji: string              // 大厅卡片/勋章图标（占位阶段用 emoji，勋章正式图后补可选）
  medal: string              // 勋章名：甄别师/清除官/小达人/安全卫士/全能小网民
  questionIds: string[] | null  // 终极关为 null，运行时随机
}
```

### 4.3 存档 `localStorage`（key: `huaiya-save`）

```ts
interface SaveData {
  clearedLevels: number[]    // 已通关关卡 id
  bestScores: Record<number, number>  // 各关最高分（答对题数）
  totalScore: number         // 累计积分
  soundOn: boolean           // 音效开关，默认 true
  nickname?: string          // 证书昵称
}
```

## 五、核心交互细节

### 5.1 答题反馈（零挫败设计）

- **答对**：鼓励动画（星星/彩带 CSS 粒子）+ 上行音效 + 鼓励文案（随机从鼓励语池取），自动/点击进入下一题。
- **答错**：温和提示动画 + 低柔音效 + 题目原图变暗高亮正确项 + 通俗解析文案，点「我知道了」进入下一题。无批评话术。

### 5.2 解锁与重玩

- 关卡顺序解锁：通关第 N 关解锁第 N+1 关；四关全通后解锁终极关。
- 已通关关卡可重玩，重玩刷新该关最高分与总积分，不重复发勋章。

### 5.3 知识小结

每关结算页自动展示本关 4 题解析的精简版知识点列表（来自题库 `explain` 字段汇总）。

## 六、美术与配图

- **UI 风格**：CSS 手绘卡通风，马卡龙明亮柔和配色（粉/鹅黄/薄荷绿/天蓝），Q 版圆角、大按钮、无刺眼配色。全部 CSS 实现，无 UI 框架依赖。
- **题目主图**：16 张，统一 4:3 横图（建议 ≥1024×768），扁平化 Q 版卡通，生成关键词见需求文档第十一章 / [配图清单](./配图清单.md)。
- **开发期占位**：按题目 id 命名的统一风格 SVG 占位图（含题目序号与简要场景文字），AI 配图生成后按同名覆盖即完成替换，无需改代码。
- **反馈环节**：不单独配图，复用题目原图 + CSS 动画与表情图标。

## 七、音频（WebAudio 合成）

`src/audio.ts` 统一管理：

| 音效 | 合成方案 |
|---|---|
| 答对 | 两音上行（如 C5→E5），短促明亮 |
| 答错 | 单音低柔（如 A3），无刺耳感 |
| 通关 | 五音上行小旋律 |
| 点击 | 极短 tick |
| BGM | 可选：极简柔和循环琶音（音量很低），首发可不含 |

浏览器自动播放限制：AudioContext 在首次用户点击后 resume。

## 八、通关证书

Canvas 2D 绘制：马卡龙卡通边框 + 5 枚勋章图形 + 称号「青少年健康上网小能手」+ 昵称（默认小槐芽）+ 日期。`toDataURL('image/png')` 触发下载。昵称仅存本地。

## 十、开发节奏（三步，每步交用户本地浏览器验证）

1. **骨架 + 全流程**：Vite 脚手架、路由、题库数据、答题页全部题型、判定与解锁逻辑、结算页（SVG 占位图）。
2. **体验完善**：答题反馈动画、WebAudio 音效、勋章中心、知识小结、证书下载、存档。
3. **打磨上线**：响应式细节（手机/平板）、AI 配图接入替换、README 完善、Vercel 部署 + Cloudflare 子域 `huaiya.535334587.xyz`。

## 十一、部署

- 仓库：GitHub public 仓库（本仓库）。
- 构建：`vite build`，`vite.config.ts` 设 `base: './'`（相对路径，支持离线双击与任意子路径托管）。
- 托管：Vercel CLI 部署（login → link → deploy --prod），Cloudflare 添加 CNAME `huaiya` → Vercel 域名。
- 同步原则：推送 GitHub 后提醒是否同步 Vercel，不自动部署。
