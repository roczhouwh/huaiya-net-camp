## 二、已修复问题明细

### 🔴 Bug-1 大厅「集齐全部勋章」横幅永不显示
- **位置**：`src/views/hall.ts`
- **问题**：原判断 `totalScore() >= 32`。但总积分 = Σ各关最高答对数，理论上限 = 4×4 + 10 = **26**，条件永远为 false，横幅永不出现。
- **修复**：改用 `isAllCleared()`（五关全通）作为横幅显示条件。

### 🔴 Bug-2 答对时配图也变暗
- **位置**：`src/views/level.ts` `paintResult()`
- **问题**：`scene.dimmed` 无条件添加，答对、答错都会变暗配图。按设计应**仅答错时变暗**以突出解析。
- **修复**：改为 `if (!correct)` 时才加 `dimmed`。

### 🟠 Fix-3 证书昵称未转义（自注入风险）
- **位置**：`src/views/cert.ts`
- **问题**：昵称来自用户输入，原本直接拼进 HTML 模板 `value="${nickname}"`。输入 `"` 或 HTML 片段可造成属性逃逸/注入（虽是本地自注入，仍应规避）。
- **修复**：模板不再内联昵称；挂载后用 `input.value = nickname` 的 JS 属性赋值方式写入，不经过 HTML 解析。

### 🟠 Fix-4 空串昵称回退失效
- **位置**：`src/views/cert.ts`（配套 `storage.ts`）
- **问题**：原用 `getNickname() ?? '小槐芽'`。当用户清空昵称时存的是空串 `''`，而 `??` 只拦截 `null/undefined`，空串不会被替换，导致显示/文件名为空。
- **修复**：改用 `|| '小槐芽'` 回退；清空输入时存空串，读取统一经 `||` 归一为默认昵称。

### 🟡 Clean-5 删除死状态 `wasWrong`
- **位置**：`src/views/level.ts`
- **问题**：`wasWrong` 字段被赋值却从未读取，属死代码，易误导后续维护。
- **修复**：从 `LevelState` 接口、初始化、`judge()`、重置逻辑中全部移除。

### 🟡 Clean-6 `lastResult` 预置污染结算页
- **位置**：`src/views/level.ts`
- **问题**：`renderLevel()` 里以 `score:0` 预置 `lastResult`。若用户中途退出再直接访问 `#/result/N`，会读到 0 分而不是已存最高分。
- **修复**：`lastResult` 只在 `finishLevel()` 通关时写入，进入关卡不再预置。
