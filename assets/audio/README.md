# 音频素材目录

把整理好的音频文件直接放到本目录即可。命名固定，代码会按文件名加载。

## 文件命名约定（.mp3 或 .ogg / .webm）

| 文件名 | 用途 | 必须/可选 |
|---|---|---|
| `select.mp3` | 通用点击 **与** 选择题选项选中（当前点击复用选中音） | 必须 |
| `click.mp3` | 独立通用点击音 —— 若有专门的点击音可新增此档，并改 `src/audio.ts` 的 `playClick` 指向 `click` | 可选 |
| `correct.mp3` | 答对 | 必须 |
| `wrong.mp3` | 答错（当前复用原 click 音充当，未来换更柔和的答错音直接覆盖此档即可） | 必须 |
| `victory.mp3` | 单关通关 | 必须 |
| `celebration.mp3` | 终极通关（比 victory 更隆重） | 可选 |
| `medal.mp3` | 获得勋章 | 可选 |
| `ui.mp3` | 弹窗/提示/未解锁 | 可选 |
| `bgm.mp3` | 背景音乐（须能无缝循环，建议 15–30s 短段） | 必须 |

> 格式优先级：代码会按 mp3 → ogg → webm 依次尝试，同一种放其一即可。

## 最小必需集
`select · correct · wrong · victory` + `bgm`，其余可选后补。

## 历史更名（2026-08-30）
为消除代码指向的名字歧义，原 `click.mp3`（实际当答错用）已更名 `wrong.mp3`；
通用点击不再单独用档，复用 `select.mp3`。详见 `src/audio.ts` 注释。

## 注意
- BGM 一定要能**无缝循环**，接缝带杂音会很突兀。
- 公开上线项目，请确认文件为**原创/免版权/已购授权**。
- 小学生向：所有音效别刺耳、别突兀，答错偏柔和。
